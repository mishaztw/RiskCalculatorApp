# RiskCalculatorApp
Программа для расчета рисков информационной безопасности

Приложение предназначено для быстрой оценки рисков ИБ на предприятиях малого и среднего бизнеса. Позволяет без специальной подготовки рассчитать величину риска, классифицировать его по уровню и визуализировать результаты.

Возможности:
- Ввод активов, угроз, вероятности и ущерба
- Расчет риска по формуле R = P × D
- Классификация рисков: Низкий / Средний / Высокий
- Визуализация в виде круговой диаграммы
- Сохранение отчета в txt-файл
- Очистка данных одной кнопкой

Технологии:
- C# (.NET 10)
- Windows Forms
- WinForms.DataVisualization
- Visual Studio 2022
